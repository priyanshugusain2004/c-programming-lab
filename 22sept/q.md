Question 1 – Student Grade Calculation
Write a C program to accept the marks of a student and display the grade according to the following criteria:
90–100: A+
80–89: A
70–79: B
60–69: C
50–59: D
Below 50: F

The program must also validate whether the entered marks are within the range 0–100.
Major concepts: if-else, nested conditions, input validation
Level: Beginner




Question 2 – Menu-driven Calculator
Write a menu-driven C program using switch to perform addition, subtraction, multiplication, and division of two numbers. The menu should continue to appear until the user selects the Exit option.
Major concepts: switch, do-while, break, arithmetic operators
Level: Beginner


Question 3 – Break and Continue
Write a C program to accept a positive integer n and display all numbers from 1 to n. The program should skip multiples of 3 using continue and terminate the loop when the value reaches 50 using break.
Major concepts: for loop, break, continue
Level: Beginner–Intermediate


Question 4 – Prime Number Using a Function
Write a C program using a user-defined function isPrime() to determine whether a given number is prime or not. The function should return 1 for a prime number and 0 otherwise.
Major concepts: Function declaration, definition, function call, return value, loops
Level: Intermediate


Question 5 – Swap Two Numbers Using Pointers
Write a C program containing a function swap() to interchange two numbers. Demonstrate the use of pointers so that the values of the original variables are changed after the function call.
Major concepts: Functions, pointers, addresses, * and & operators
Level: Intermediate


Question 6 – Factorial Using Recursion
Write a C program to calculate the factorial of a positive integer using a recursive function. Display the sequence of recursive calls for a suitable value such as 5 through appropriate output statements.
Major concepts: Recursion, base condition, function call stack, return value
Level: Intermediate


Question 7 – Student Result Processing System
Develop a menu-driven Student Result Processing System using user-defined functions. The program should accept marks in three subjects, calculate total and percentage, determine pass/fail and grade, and display the result.

Use separate functions for input, calculation, grade determination, and display.
Major concepts: switch, do-while, if-else, functions, arguments, return values
